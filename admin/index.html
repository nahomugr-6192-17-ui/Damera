Supabase Quick Setup Instructions

  1. Open your Supabase project dashboard at https://supabase.com
  2. Go to the SQL Editor and execute the script in supabase/schema.sql
  3. In Vercel project settings, set two environment variables:
    • SUPABASE_URL = https://your-project.supabase.co
    • SUPABASE_SERVICE_ROLE_KEY = your-service-role-secret-key
  4. Redeploy on Vercel — the dashboard will instantly switch to cloud PostgreSQL persistence!

Reset All Analytics Data?

This action will permanently delete all historical raw telemetry events, player profiles, sessions, and alerts. This action cannot be undone.

Administrator accounts and Telegram configurations will not be affected.
